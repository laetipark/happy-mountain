## 남은 실기기 확인

연결된 Android 기기와 API 키, Mac 환경이 없어 다음은 실행하지 못했습니다.

- Android 설치·실행, OS 위치 권한 허용/거부/대략적 위치, GPS 꺼짐과 설정 복귀
- 실제 카카오 인증·지도 렌더링·카메라 제스처·표식 선택
- 실제 승인된 기상청 키로 날씨 응답 확인
- 실제 기기에서 백그라운드 복귀, 화면 회전, 재실행 시 지도·위치 자원 동작
- iOS CocoaPods 설치, Xcode 컴파일·서명·iPhone 실행
- 실제 JavaScript 키를 사용하는 카카오 웹 지도 인증·타일·제스처·표식 선택
- iPhone Safari·Android Chrome 실기기의 위치 권한과 화면 동작

컨트롤러·위젯 테스트로 첫 위치 승인 후 갱신, 거부 상태, 추적 중단·복구, 오래된 응답 차단, 공유 필터, 오류·재시도 상태는 확인했습니다. 이는 운영체제 권한 대화상자나 네이티브 SDK 실기기 검증을 대체하지 않습니다.

Mac에서는 현재 KakaoMapsSDK 바이너리를 읽을 수 있는 최신 Xcode를 사용하세요. iOS 빌드·설치는 [모바일 안내서](../README.md)의 절차를 따릅니다.

## Windows 브라우저 테스트 환경

Flutter 3.47.5 테스트 서버가 CanvasKit URL을 Windows 파일 경로로 변환해 404를 반환하는 문제를 확인했습니다. 저장소 전용 SDK에서 URL의 `/` 구분자를 그대로 유지하도록 한 줄을 보정한 뒤 Chrome 테스트가 통과했습니다. 원본 파일·도구 캐시는 `.tooling/flutter-test-workaround`에 보존했습니다. SDK 버전과 앱 배포 코드는 바꾸지 않았습니다. 정확한 보정 위치는 [웹 실행 안내](web.md)에 있습니다.

release 웹에 Flutter가 생성하는 `flutter_service_worker.js`는 이전 등록을 해제하는 정리용 코드입니다. 앱 시작 코드에서 서비스 워커를 등록하지 않으며 PWA·오프라인 앱 실행은 제공하지 않습니다.
