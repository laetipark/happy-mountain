# 구성과 데이터 의미

## 공통 앱

`lib/domain`은 좌표, 날씨, 경보 기록, 필터와 저장소 계약을 정의합니다. 시각은 UTC 순간으로 보관하고 표시는 한국 시간으로 변환합니다. 기간 필터는 한국 달력 날짜이며 시작일·종료일을 포함합니다.

`lib/data`는 HTTP 요청, 기상청 격자 변환, 예보 선택, 카카오 검색, 공개 경보 CSV와 캐시를 담당합니다. `lib/app`은 권한, 화면 상태와 요청 순서를 관리합니다. 화면과 네이티브 지도 사이의 계약은 [native-map.md](native-map.md)에 있습니다.

웹은 같은 출처의 Node.js 서버에서 공개 설정을 가져옵니다. `AppCapabilities`로 장소·날씨 기능 사용 가능 여부를 판단하므로 브라우저가 REST·기상청 키를 가질 필요가 없습니다. 저장소의 `gatewayOrigin`이 지정되면 고정 `/api/*` 경로를 호출하며, 네이티브는 기존 공급자 HTTPS 주소를 직접 호출합니다. `/api/history`는 서버가 JSON-LD에서 발견한 CSV의 원본 바이트와 수정일을 전달합니다. 파서와 날씨 계산은 공통 Dart 코드입니다.

카메라 이동은 지연 처리하고 오래된 응답은 무시합니다. 위치 갱신이 사용자의 지도 탐색을 덮어쓰지 않습니다. 산 검색과 경보 주소 좌표 검색은 별도 요청으로 관리하며, 같은 주소는 재사용합니다. 경보 목록은 모든 기록을 유지하고 지도만 주소당 최신 기록으로 묶습니다.

## 경보 이력

- 출처: https://www.data.go.kr/data/15092027/fileData.do
- 의미: 산림청 국립산림과학원이 공개한 **대형산불위험예보 이력**입니다. 현재 유효 경보 또는 실시간 위험지수가 아닙니다.
- 상세 페이지의 JSON-LD에서 CSV 다운로드 주소를 매번 발견합니다. 파일 ID를 고정하지 않습니다.
- CSV 응답의 charset 표기와 실제 인코딩이 다를 수 있어 bytes를 UTF-8 또는 CP949로 디코딩합니다.
- 열 이름으로 파싱하고 잘못된 행 수를 기록합니다. 필수 열 변경이나 해석 불가능한 파일은 오류로 처리합니다.
- 기본 조회는 실제 자료 최신일 기준 최근 두 달입니다. 월말은 해당 월의 마지막 날짜로 보정합니다.
- 시도 약칭·과거 이름을 정규화하고 미지의 이름은 그대로 보존합니다.
- 모바일은 앱 전용 지원 디렉터리의 JSON, 웹은 IndexedDB에 캐시합니다. 한국 날짜 기준 하루마다 갱신합니다. 수동 새로고침은 서버 캐시도 건너뛰며 실패 시 기존 자료와 갱신 실패 안내를 함께 제공합니다. 저장 실패는 새 자료 조회를 막지 않습니다.
- 캐시는 이동 이력을 저장하지 않습니다.

## 날씨

WGS84 위경도를 기상청 5km 격자로 변환합니다. 단기예보의 02/05/08/11/14/17/20/23시(KST) 회차에서 제공 지연 10분을 적용한 최신 회차를 사용합니다. 현재 이후 가장 가까운 하나의 예보시각에서 TMP/REH/SKY/PTY/WSD/VEC 여섯 값을 함께 선택합니다.

날씨는 관측 실황이 아닌 예보이며 화면에 예보시각을 표시합니다. API 키는 URI에 한 번만 인코딩합니다. 지도 SDK와 카카오 Local REST의 키 종류는 서로 다릅니다.

## 플랫폼

Android와 iOS의 카카오 지도 SDK v2를 직접 Platform View로 연결합니다. 네이티브 지도 생명주기를 앱 전경·배경 상태와 연결하고, 뷰 폐기 시 채널·콜백·지도 엔진을 해제합니다.

웹은 `HtmlElementView`와 JavaScript interop으로 카카오 웹 지도를 연결합니다. 지도 위 컨트롤에는 포인터 차단을 적용하며 다른 화면·대화상자가 열리면 지도 입력을 중지합니다. 웹 위치 권한은 사용자가 현위치 버튼을 누를 때 요청합니다. 넓이 1,024px 이상에서는 지도와 400px 이력 패널을 함께 표시합니다.

파일 접근·Isolate 실행과 브라우저 저장·실행은 조건부 import로 나눕니다. 웹에서는 메인 이벤트 루프에서 공통 파서를 실행하며 별도 Web Worker는 사용하지 않습니다.

Android 테스트 패키지는 `com.example.happy_mountain.mobile`입니다. iOS는 밑줄을 허용하지 않는 번들 ID 규칙에 맞춰 `com.example.happy-mountain.mobile`을 사용합니다.

웹 중계 서버는 외부 API 연결과 정적 파일 제공만 담당합니다. 로그인, 알림, 백그라운드 위치, 경로 기록, 데이터베이스, PWA 설치는 제공하지 않습니다.
